# PokerCal Web

Browser version of PokerCal for settling poker buy-ins, cash-outs, and shared food expenses. The calculator preserves a zero-sum result while rounding settlements to increments of five.

Game data is saved only in the current browser with `localStorage`.

## Development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
npm test
```
